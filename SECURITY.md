# Security policy

Ancorhash is at an early stage, and its code, including `AncorhashRegistry`,
has not been audited. Do not rely on it on mainnet yet.

## Reporting a vulnerability

Report vulnerabilities privately, with **Report a vulnerability** in the
[Security tab](https://github.com/N0g4D/ancorhash/security) of this
repository. Never open a public issue for a vulnerability.

The aim is to answer every report within a week.
